This is a responsive personal portfolio website built with HTML5 and CSS3 only. It has a navigation bar, a hero section, About, Skills, Projects, Contact and Footer sections, and each navigation link jumps to the correct section. I used semantic tags, CSS variables for the colour palette, Flexbox for the header and hero, and CSS Grid for the About layout and project cards. A media query adjusts the layout for phones, and the buttons, links and project cards have hover and focus styles.
